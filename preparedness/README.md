# Preparedness — routing map

A Panama-specific guide to household emergency preparedness, built from official SINAPROC guidance and real local prices. Not a generic prepper plan: every price is a real Oct-2026 Panamanian retail figure (USD), and the goal is a plan someone with little money can build up gradually.

## How to read

1. Start with `plan.md` — the household plan and alert system everything else plugs into.
2. Then the kits: `water.md`, `food.md`, `first-aid.md`, `supplies.md` + `shelter.md` (equipment).
3. `go-bag.md` — the evacuation bag (SINAPROC "mochila de 72 horas").
4. `home.md` — hardening your home for quake/flood/wind.
5. `no-internet.md` — preparing for weeks without internet (person + business): cash, documents, radio, offline operations.
6. `jungle.md` — situational: only if you must enter or are stranded in tropical forest (read its §0 first).
7. `budgets.md` — three budget tiers (Básico / Estándar / Mejorado) with real numbers.

## Conventions

- Prices are USD (Panama uses the US dollar, balboa 1:1), captured Oct 2026, and fluctuate — re-verify before buying.
- Groceries: Super Xtra, Super 99, El Rey, Riba Smith, Super Barú. Hardware: DoIt Center, Novey, El Machetazo. Meds: Farmacias Arrocha, Farmás, Super Xtra farmacia. **Supermarket prices beat minisúper/abarrotería** (see `food.md`).
- "Not found" means we could not verify a real price and refused to guess.
